# CS103: Mathematical Foundations of Computing

Quarter: Spring 2025 (Stanford course archive `cs103.1256`)

## Grading

> Raw Score = 0.20 · PSet Score + 0.75 · Exam Score + 0.05 · Participation Score

| Component     | Weight |
| ------------- | ------ |
| Problem Sets  | 20%    |
| Exams         | 75%    |
| Participation | 5%     |

### How each component score is computed

> PSet Score = sum of square roots of problem set scores / sum of square roots of point totals

> Exam Score = 1/6 · First Midterm + 1/3 · Second Midterm + 1/2 · Final Exam

> Participation Score = min{1, (lectures answered) / (lectures with PollEV - 3)}

No lowest problem set score is dropped. The participation denominator subtracts 3, so students
may miss three PollEV lectures without penalty.
